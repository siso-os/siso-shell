Why this template exists

his words · the reading · the ceilings

  1. His words 1

    verbatim, from 00_AGENT_ZERO/source/ — never paraphrased

    templates for like our project one pager which leads to all of the other project Cloudflare … loads of different repos, but we want like a set kind of UI templateShaan · 6 Sep 16:36

  2. Reading authored by the seat

    His 16:36: 'templates for like our project one pager which leads to all of the other project Cloudflare … loads of different repos, but we want like a set kind of UI template'; 18:19: 'title subtitle paragraph … mind map … link to all of the repos … all of the research what the research means … all of the docs the progress what agents we've had running on here the timeline'. This is the hub: every other page is one hop from it.

    Readers. Human: the whole project in one screen, then click out. Agent: the entry to resume a project: front door, repos, verification lines, open modules.

    1. What is this project and for whom?
    2. Which repos, which are private, what is the head commit?
    3. What is live (URLs) and does it return 200?
    4. What landed, what is left, who is on it?
    5. What did he say about it, when?
    6. Which questions, industries and Works does it touch?

  3. What this page may claim

    Claim ceilingRepo heads and HTTP codes from live lookups with their timestamp; 'landed' only when verified against a remote or URL; his words verbatim from source/.
    Data it rendersplan/projects.json (this repo) + /.agents/{PAGE.md,HANDOFF.md,owners.log,page.url,repos.json} + bin/az-projects-table live cache; the same JSON feeds the project's own pages.dev front door and its Library Work.
    PrivacyPublic front door for agency projects; client projects show repo names, visibility and dated activity, never payload.
    Empty stateNo URL → 'no live page yet' + the publish play; no owner → 'unowned' in red.
    Agent entry<repo>/.agents/PAGE.md (read first) · bin/az-projects-table
